# Grill Me

Purpose: Challenge assumptions and surface weak points before execution.

Checklist:
- Identify the top 3 execution risks.
- Call out unknowns that can block delivery.
- Propose one mitigation per risk.
- Require explicit verification evidence for each claim.

Output format:
1) Risks
2) Unknowns
3) Mitigations
4) Verification gates
