# Meta-Reasoning Reflection Loop

Before finalizing a major step, run a compact reflection cycle:

1. What went well?
2. What failed or degraded quality?
3. What should change in the next strategy?

Always produce a short reflection object with:

- `what_went_well`
- `what_failed`
- `what_to_improve`
- `recommended_shift`

Use prior reflections from session memory to avoid repeating low-scoring strategies.
