# Full Swarm Autonomy

Coordinate all self-improvement layers in this order:

1. Meta-reasoning + reflection.
2. Memory evolution + lessons learned.
3. Agent initiative proposals.
4. Long-horizon autonomous routine execution.

## Guarded mode policy

- If pending approvals exist, run in guarded mode.
- Auto-apply only low-risk, low-impact proposals.
- Keep high-risk suggestions/manual memory updates pending until explicit review.
