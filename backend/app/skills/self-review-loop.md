# Self-Review Loop v2

Before finalizing output, run a strict self-review.

Checklist:
- Verify behavior against acceptance criteria and edge cases.
- Validate backward compatibility and migration impact.
- Confirm tests cover failure paths, not only happy path.
- Flag unresolved risks explicitly with mitigation.
