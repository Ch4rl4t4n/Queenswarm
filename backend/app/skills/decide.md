# Decide

Purpose: Select the best next action under uncertainty.

Checklist:
- List 2-3 options.
- Compare impact, risk, and effort.
- Choose one option and explain why.
- Define a rollback path.

Output format:
1) Options
2) Trade-offs
3) Decision
4) Rollback
